# 🎬 YouTube Timestamp Marker (Chrome Extension)  

A lightweight **Chrome extension** that lets you **bookmark and manage timestamps** in YouTube videos.  
Quickly jump back to the exact moments you want without scrubbing through the entire video.  

---

## 🚀 Features  

- ⏱️ Add and label custom timestamps while watching YouTube videos  
- 📌 Manage multiple bookmarks per video  
- 🔎 Navigate instantly to saved timestamps  
- 💾 Persistent storage to keep your timestamps across sessions  
- 🖥️ Clean and simple Chrome extension interface  

---

## 🛠️ Tech Stack  

- **Platform:** Chrome Extension (Manifest V2)  
- **Languages:** JavaScript, HTML, CSS  
- **Storage:** Chrome Storage API  

---

## 🎮 Usage  

1. Open any YouTube video.  
2. While watching, press **`U`** to instantly bookmark the current timestamp.  
3. Open the extension’s **popup** (click the extension icon in Chrome).  
4. The **popup.html** shows a list of all your saved timestamps for that video.  
5. Click on any timestamp to jump back to that exact moment in the video.  

## 📌 Use Cases  

- Study YouTube lectures/tutorials and revisit key concepts  
- Save highlights from long podcasts, music mixes, or livestreams  
- Track workout steps, cooking recipes, or DIY instructions  
- Bookmark favourite scenes from entertainment content  

---

## 📥 Installation  

1. Clone this repository  
2. Open `chrome://extensions/` in your browser  
3. Enable **Developer Mode**  
4. Click **Load unpacked** and select this project folder  
5. Start bookmarking your favourite timestamps 🎉
